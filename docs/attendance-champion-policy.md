# 출석왕 보상 정책

## 목적

월간 출석왕에게 다음 달에 사용할 무료 참여 쿠폰을 자동 발급한다. 이 문서는 동률 인원에 따른 보상 횟수와 정책 변경 원칙의 source of truth다. 출석왕 후보 집계 자체는 `docs/statistics-policy.md` 및 `docs/domain-model.md`를 따른다.

## 현재 정책: `champion-reward-v1`

일반 출석(`NORMAL`)만 출석왕 집계에 포함한다. 쿠폰을 사용한 출석을 포함한 모든 무료/쿠폰 출석은 제외한다.

해당 월에 `NORMAL` 출석을 한 일반 회원(`MEMBER`) 중 출석 횟수가 가장 많은 회원이 수상한다. 운영진(`STAFF`)과 모임장(`LEADER`)은 집계에서 제외한다. 최소 출석 횟수나 수상 시점의 회원 상태에 따른 별도 제한은 없다. 따라서 월중 탈퇴한 일반 회원도 그 달의 유효 `NORMAL` 출석이 최다이면 수상한다. 자격을 갖춘 일반 회원의 `NORMAL` 출석자가 없는 달에는 수상자를 발급하지 않는다.

| 공동 1등 인원 | 각 수령자의 무료 쿠폰 사용 가능 횟수 |
| --- | --- |
| 1명 | 2회 |
| 2명 | 2회 |
| 3명 이상 | 1회 |

공동 1등인 모든 회원이 해당 구간의 보상을 받는다. 예를 들어 공동 1등이 3명이면 세 사람 모두 1회 사용 가능한 쿠폰을 받는다.

## 변경 가능성 및 이력 보존

보상 규칙은 코드에 흩어 놓지 않는다. Phase 5에서 `ChampionRewardPolicy`를 버전과 적용 시작 월을 가진 전용 설정으로 구현한다. 각 정책 구간은 동률 인원 범위와 쿠폰 사용 가능 횟수를 가진다.

정책을 바꿀 때는 기존 정책을 수정하지 않고 이후 대상 월에 적용할 새 버전을 추가한다. `AttendanceChampionAward`에는 실제 적용한 `policyVersion`과 `rewardUses`를 저장하고, 발급 쿠폰의 `totalUses`도 그 값을 따른다. 따라서 과거 Award와 이미 발급된 쿠폰은 정책 변경 뒤에도 바뀌지 않는다.

같은 대상 월과 회원에는 하나의 Award만 확정할 수 있게 하여 재실행이나 정책 변경으로 인한 중복 발급을 막는다.
## 관리자의 수상 취소

자동 발급된 출석왕 보상도 관리자가 취소할 수 있다. 취소는 `AttendanceChampionAward`를 삭제하지 않고
`CANCELLED`로 변경하며, 연결된 미사용 쿠폰은 `VOIDED`로 변경한다. 이미 한 번이라도 사용된 쿠폰이 있으면
출석·쿠폰 잔여 횟수·사용 이력이 함께 맞아야 하므로, 먼저 해당 사용을 취소한 뒤 수상을 취소해야 한다.

수상 확정 뒤 출석을 수정하더라도 이미 확정된 보상은 자동으로 다시 계산하거나 회수하지 않는다. 관리자가
수상을 취소한 뒤 필요하면 해당 월 보상을 다시 확정한다.

연결된 출석왕 쿠폰만 따로 `VOIDED`로 바꾸는 것은 허용하지 않는다. 반드시 수상 취소 API를 사용해
수상 상태와 쿠폰 상태를 같은 트랜잭션에서 함께 변경한다.
