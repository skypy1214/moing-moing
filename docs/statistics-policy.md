# 월별 통계 정책 초안

## 목적

월별 통계는 확정된 계산 규칙에 따라 결과와 근거를 함께 반환한다. 이 통계는 출석왕 보상 자동 발급과는 별도로 사용한다.

## 2026-08-24 확정 규칙

- 월별 통계의 분모는 회원의 가입일~탈퇴일이 해당 월과 하루라도 겹치는 모든 회원이다. 따라서 7월 1일 가입 후 7월 5일 탈퇴한 회원도 7월 분모에 포함한다. 가입일과 탈퇴일 모두 재적 기간에 포함한다.
- 활동률 분자는 해당 월에 출석한 회원과 활동 중단 기간이 해당 월과 하루라도 겹치는 회원의 합집합이다. 두 조건을 모두 만족한 회원은 한 명으로만 계산한다.
- 화면에는 적용 정책 버전을 표시하지 않고, 분모와 같은 기준의 `해당 월 모임원` 수를 표시한다.

## 이전 초안 (참고)

- 대상 회원(분모): 해당 월과 회원의 가입일~탈퇴일 기간이 하루라도 겹치는 회원. 탈퇴일은 대상 기간에 포함한다.
- 출석률 분자: 대상 회원 중 해당 월의 취소되지 않은 출석을 한 번 이상 기록한 회원 수. `NORMAL`과 `COUPON` 모두 출석률에는 포함한다. 취소된 출석과 취소된 모임의 출석은 제외한다.
- 활동률 분자: 출석률 분자와 해당 월에 활동 중단 기간이 하루라도 겹치는 대상 회원의 합집합. 이미 출석한 활동 중단 회원은 한 명으로만 센다.
- 분모가 0이면 비율은 `0`으로 반환한다.

`GET /api/v1/statistics/monthly?month=YYYY-MM`은 분자·분모·비율, 대상 회원과 출석/활동 중단 회원 ID를 반환한다.

## 출석왕 보상 정책 (확정, 구현은 Phase 5)

출석왕은 이 통계 API와 별도로 `NORMAL` 출석만으로 계산한다. 공동 1등 인원에 따라 각 수령자에게 발급하는 무료 쿠폰 사용 횟수는 다음과 같다.

| 공동 1등 인원 | 수령자별 쿠폰 사용 횟수 |
| --- | --- |
| 1명 | 2회 |
| 2명 | 2회 |
| 3명 이상 | 1회 |

규칙은 `ChampionRewardPolicy`의 버전별 구간 설정으로 관리한다. 확정된 Award에는 정책 버전과 `rewardUses`를 저장하므로, 나중에 규칙을 바꾸어도 과거 발급 결과는 변하지 않는다.

출석왕 자격은 해당 월에 `NORMAL` 출석을 한 회원 중 최다 출석자로 확정했다. 최소 횟수와 탈퇴 상태는 추가 제한이 아니며, `NORMAL` 출석자가 없으면 수상자도 없다.

## 아직 결정하지 않은 항목

- 월중 가입·탈퇴와 일부 기간 활동 중단을 월별 지표에 포함하는 정책을 이 초안 그대로 확정할지.
- 출석왕 후보 미리보기와 쿠폰 자동 발급의 분리·확정 절차.

이 항목은 `docs/open-questions.md`의 OQ-06~OQ-09와 함께 결정한다.
