# 연속 수업과 선납 관리

## 신규 연속 수업

- 수업을 개설할 때 `연속 수업으로 개설`을 선택한다.
- 시작일을 기준으로 같은 요일의 수업을 2~24회 자동 생성한다.
- 선납 기본 금액은 `회당 참가비 × 수업 횟수`이며, 회원별로 필요한 경우에만 수정한다.

## 기존 수업 전환

- 개별 수업의 수정 창에서 `수업 묶기`를 선택하고, 아직 연속 수업에 속하지 않은 출석 종료 전 수업을 둘 이상 선택한다.
- 기존 Gathering과 Attendance는 삭제하지 않는다. 선택한 수업에만 `classSeriesId`를 연결한다.
- 기존 참석자 중 선납 회원으로 선택한 사람의 일반 출석은 `PREPAID`로 전환한다. 선택하지 않은 사람의 기존 입금 상태는 유지한다.
- 전환한 선납금은 연속 수업의 첫 수업일 기준으로 정산 수입에 한 번 반영한다.

## 결석과 환불

- 선납 회원의 결석 회차는 자동 이월·환불하지 않는다.
- 환불은 모임의 개별 운영 규칙에 따라 수기로 정산한다.
